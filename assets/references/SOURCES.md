# Visual reference notes

These six reference images were supplied by the project owner and copied into this folder for the local Capri companion prototype:

- `poses.jpg` — pose sheet, used as the current on-screen sprite source.
- `expressions.jpg` — facial expression and animation reference.
- `panel.png` — settings and chat layout reference.
- `desktop.jpg` — desktop placement and chat composition reference.
- `arrive.jpg` and `teleport.jpg` — arrival and teleport effect references.

The pose sheet is displayed as provided with a luminance key to suppress its near-black background. It remains a JPEG source image; individual sprite layers have not been reconstructed from the upstream repository.

The upstream project maintains a separate source manifest at [reference/SOURCES.md](https://github.com/TheAgencyMGE/capri-companion/blob/main/reference/SOURCES.md). It says the repo contains no copyrighted images and lists official frames viewed for reference only, identifying them as © CD PROJEKT / Studio Trigger / Netflix. The upstream README likewise states the MIT license covers code and not Capri's design/art. These notes are retained here to keep the distinction clear. This prototype is an unofficial fan project; this note does not grant rights to the character or images.
